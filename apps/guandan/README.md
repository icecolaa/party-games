# 🃏 掼蛋（Guandan）

4 人两队（对家为队友）· 两副牌 108 张 · 逢人配 · 完整牌型与炸弹层级，人机对战 + 联机对战，移动端适配。

## 玩法

- **队伍**：4 人两两成队，座位 0&2 一队、1&3 一队（对家即队友）
- **牌**：两副牌共 108 张，每人 27 张
- **级牌**：当前所打的级数（如打 2 时的 2）牌力仅次大小王
- **逢人配**：红桃级牌是万能牌，可代替除大小王外的任意牌
- **牌型**：单张 / 对子 / 三张 / 三带二 / 顺子(5) / 三连对(6) / 钢板(6) / 炸弹 / 同花顺 / 天王炸
- **炸弹大小**：4 炸 < 5 炸 < 同花顺 < 6 炸 < 7 炸 < 8 炸+ < 天王炸
- **升级**：头游 + 队友二游升 3 级、三游升 2 级、末游升 1 级
- **获胜**：先打过 A 的队伍获胜

## 运行

```bash
node ../../servers/guandan-standalone.js          # 联机服务器，默认端口 8700
# 或直接双击 index.html 玩人机对战（联机需启动服务器）
```

联机：创建房间得 4 位房间号 → 分享给好友 → 凑齐 4 人（房主可加 AI 补位）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `css/style.css` | 样式（移动端优先，含安全区适配与多断点） |
| `js/gd-core.js` | 规则核心：牌型识别、逢人配合成、炸弹层级、候选生成 |
| `js/gd-ai.js` | AI 决策：队友意识、不拆牌型、炸弹保留 |
| `js/gd-game.js` | 游戏引擎：发牌、轮次、升级、终局 |
| `js/gd-ui.js` | 界面渲染、本地对局驱动、联机客户端 |
| `server.js` | 静态服务 + WebSocket 房间（服务器权威，手牌脱敏） |
| `tests/` | 测试套件 |
