# 🂡 智能德州扑克（Texas Hold'em AI）

单机 AI 对战 · 双人本地热座 · 联网房间对战，2~8 人同桌的德州扑克完整实现。
AI 基于蒙特卡洛模拟精确估算胜率，并结合底池赔率、位置、对手行为做出策略决策。

## 功能

### 游戏玩法
- 标准 No-Limit Texas Hold'em：翻牌前/翻牌/转牌/河牌四轮下注
- 支持弃牌 / 过牌 / 跟注 / 加注 / 全下，最小加注额校验
- 多人全下时**主池/边池精确分池**，平分底池时余码分配
- 盲注轮转、单挑盲注特例、超时/断线自动过牌弃牌、淘汰赛制

### AI 策略
- **蒙特卡洛胜率估算**：每步数百~上千次随机发牌模拟（按难度分档）
- **底池赔率**：跟注前对比实际胜率与所需胜率，全下按纯赔率决策
- **位置意识**、**对手建模**（激进度/跟注站识别）、**诈唬与半诈唬**
- 五档难度：新手 / 入门 / 进阶 / 困难 / 大师（会慢打设陷阱）+ 混合模式

### 双人本地热座
- 两人同设备轮流操作，**换手隐私屏**防止偷看：行动结束立即盖牌，
  下一位玩家确认就位后才亮牌

### 联网对战
- `node server.js` 启动对战服务器（**零依赖**，WebSocket 为纯 Node 实现的 RFC6455）
- 房间制：创建房间 → 4 位房间号邀请好友，房主可加 AI 补位（0~6）
- **服务器权威**：每个房间独立 vm 沙箱运行引擎，客户端只收到脱敏状态，
  底牌在摊牌前不会离开服务器
- 断线重连回原座位、行动 45 秒倒计时、局间 7 秒继续倒计时

### 界面
- 绿绒牌桌、座位环绕布局、发牌动画、下注筹码、庄家钮
- 实时**胜率提示**（蒙特卡洛估算 + 跟注所需胜率）、完整对局日志
- 摊牌弹窗揭示全部牌型，每局结算与终局积分榜

## 快速开始

```bash
# 方式一：直接打开（单机 / 双人热座）
# 双击 index.html 即可

# 方式二：本地服务器 + 联网对战
node server.js          # 默认端口 8899
# 浏览器访问 http://127.0.0.1:8899/
# 朋友访问 http://<你的IP>:8899/ → 联网对战 → 加入房间
```

```
server.js             静态服务 + WebSocket + 房间 + 引擎沙箱
tests/                测试套件
```
