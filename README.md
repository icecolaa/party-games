# 智能五子棋

人机对战五子棋（15×15 无禁手、自由规则），纯前端实现，无需安装任何依赖。

在线仓库：https://gitee.com/ice-colaa/wuziqi

## 运行方式

- **本地完整服务**（人机 + 联机）：`node server.js` 后访问 <http://127.0.0.1:8642/>（可用 `PORT` 环境变量改端口）
- **纯人机**：双击 `index.html` 直接玩（无联机功能）
- **部署**： PocketBay 等 PaaS 直接上传 `package.json` / `server.js` / `index.html` / `ai.js` 打包即可，平台会以 `npm start` 启动并注入 `PORT`

## 功能

- 三档 AI 棋力（入门 / 进阶 / 大师），可随时切换，立即生效
- 可选先手方（玩家执黑或 AI 执黑）
- 悔棋（撤销一整个回合）、新对局、胜负比分持久化（localStorage）
- 联机双人对战：创建房间得 4 位房码，分享房码或邀请链接，好友加入即开战；长轮询实时同步、断线提示、刷新恢复座位、终局互换黑白再战（`server.js` 纯 Node 零依赖）
- 手机端适配：响应式布局（状态栏置顶、面板单列）、触摸两段式落子（点选预览 → 确认，防误触）、棋盘区禁用滚动/双击缩放、安全区适配
- 悬停虚影提示落点、最后一手标记、获胜五子高亮连线
- 终局自动判定：横 / 竖 / 双斜五连（含长连）获胜，棋盘下满判平局

## AI 设计（`ai.js`）

1. **威胁强制应手**：搜索的每个节点先做战术检查——己方一步成五立即取胜；对方存在成五点时强制拦截（对方有两处成五点则直接判负），强制挡四路径向下延伸，避免漏杀。
2. **棋型评估**：落子点沿四个方向识别活四 / 冲四 / 活三 / 眠三 / 活二等棋型，双四、四三、双活三组合额外加分；叶子节点用全盘五格滑窗估值。
3. **迭代加深 α-β 剪枝**：从 2 层逐步加深到 4 层（大师级），超时自动保留上一层完整结果；走子按攻防综合分排序提高剪枝效率。入门档在前几个高分点中随机选择以增加变化。

## 测试

```bash
node test.js      # AI 逻辑与胜负判定（20 项）
node test-mp.js   # 联机服务器 API（11 项）
```

覆盖胜负判定（四个方向 + 长连 + 隔断）、AI 战术（立即取胜 / 挡冲四 / 挡活三 / 抢双四杀交叉点 / 挡活四）、AI 自对弈终局、对随机对手胜率、大师级耗时；联机部分覆盖房间创建/加入/满员、座位恢复、落子校验、完整对局胜负、长轮询唤醒、再战换边、满盘平局等。

## 调试钩子

页面暴露 `window.__gomoku = { S, doMove, newGame, undo }`，用于浏览器端自动化测试与调试（例如直接构造连五局面验证终局 UI），不影响正常游玩。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 界面与对局流程（canvas 绘制棋盘，人机 / 联机双模式） |
| `ai.js` | AI 核心逻辑，浏览器 / Node 通用 |
| `server.js` | 联机服务器：静态托管 + 房间 API + 长轮询同步（零依赖） |
| `package.json` | Node 应用描述（`npm start` 启动服务器） |
| `test.js` / `test-mp.js` | AI 逻辑 / 联机服务器自动化测试 |
